# Engineering standard v0.1

The executable catalog is in `packages/standards/src/v0.1/index.ts`. It covers product flows, architecture, authentication, authorization, validation, data integrity, secrets, dependencies, error handling, async/idempotency, API design, uploads, abuse prevention, observability, recovery, testing, performance, accessibility, maintainability, and deployment.

Each stable rule includes applicability, severity guidance, evidence requirements, remediation, verification, and references where appropriate. A reported absence means “not visible in the inspected repository,” never “proven absent in production.” Serious findings need concrete file-and-line evidence and are downgraded to human verification when confidence is low.
