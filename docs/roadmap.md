# Roadmap

1. Expand framework-aware parsing using TypeScript ASTs and trace middleware, authentication, and data-access helpers.
2. Add opt-in, sandboxed runtime profiles with exact command previews, confirmation, timeouts, and output caps.
3. Add explicit package-manager audit profiles and advisory reachability.
4. Implement an OpenAI adapter only after credential gating, excerpt minimization, injection defense, structured output, and evidence validation are tested.
5. Grow independently labeled fixtures and publish precision/recall by stack and rule.
6. Add report comparison so teams can verify fixes and prevent regressions.
